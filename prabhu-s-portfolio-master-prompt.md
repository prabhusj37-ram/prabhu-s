---

## 0. WHAT THIS PROMPT IS

Build a complete, modern, premium, highly interactive personal portfolio website for **Prabhu S**, a Digital Marketer and aspiring Digital Marketing professional.

This is **not** a basic resume site. It should feel like:

**Personal Brand + Digital Marketing Portfolio + Mini Marketing Agency + Interactive Case Study**

The reference aesthetic (a motorsport poster artwork of a driver mid-race) should be translated — not copied literally — into the web design through these principles:

- **Dynamic diagonal composition** instead of flat centered blocks — hero, section dividers, and cards get subtle angled cuts/clip-paths that create forward motion.
- **Poster-scale typography** — oversized, bold, tight-tracking headlines that dominate the first screen, the way a poster headline dominates a print.
- **Speed-trail motion graphics** — thin animated gradient lines/streaks that sweep across sections on scroll (echoing motion blur), used as dividers, underlines, and hover states — never literal racing graphics.
- **One dominant hero visual** — a single strong focal element per section (a dashboard mockup, a case-study screenshot, a metric card) treated like a "hero shot," with everything else supporting it.
- **High-contrast color blocking** — large flat color fields meeting at hard edges (not soft blends everywhere), so sections feel graphic and confident rather than washed-out.
- **Energy without noise** — motion is purposeful and punchy (fast eases, sharp reveals) rather than slow/dreamy, but must stay professional and never feel gimmicky for a B2B marketing audience.

Keep this energy in service of the goal: a recruiter, HR manager, or small-business client should think **"this person understands digital marketing and knows how to present it professionally"** within 10 seconds.

## 3. VISUAL SYSTEM

**Theme:** sophisticated dark theme.

- Primary background: deep navy / near-black
- Primary accent: electric purple or blue
- Secondary accent: green (used only for genuine growth/status indicators, never fake metrics)
- Text: white; secondary text: light gray

**Techniques:**
- Glassmorphism panels, soft borders, subtle shadows
- Large poster-scale typography for headlines; clean, readable body type
- Rounded cards, but with at least one angled/diagonal section per major block to keep the poster energy alive (e.g., a skewed background color field behind a section, a diagonally clipped image)
- Gradient text on key headlines only (don't overuse)
- Thin animated speed-trail lines as section dividers and hover accents
- Floating UI elements (metric cards, badges) with slow drift + shadow
- Data visualization: real charts/graphs used only as visual concepts, clearly not fabricated results
- Smooth, fast-eased transitions — energetic, not sluggish

Use gradients and diagonal cuts carefully — the site must still read as clean, credible, and professional, not like a gaming or event poster. This is a B2B/recruiter-facing marketing portfolio.
